# TASK-024: Повышение устойчивости HealthChecker и легковесный опрос Slave API

## Описание задачи
Устранить ложные срабатывания мониторинга (`context deadline exceeded`) и всплески задержек при опросе нод сети.

## Выполненные работы
- [x] В **HealthChecker** увеличен дефолтный таймаут опроса нод с 5s до 10s (переменная `HEALTHCHECK_TIMEOUT_SEC`).
- [x] Добавлен немедленный повторный запрос (Immediate Retry) при первом сбое для фильтрации транзиентного джиттера.
- [x] Реализован порог подтверждения сбоя (`FailureThreshold = 2`), исключающий ложные тревоги в Telegram при разовых задержках.
- [x] На стороне **Slave API** эндпоинт `/health` переведен на легковесный режим (проверка активного интерфейса в ядре `< 0.1ms` вместо постоянного запуска тяжелого bash-скрипта).
- [x] Добавлены модульные тесты для проверки повторных попыток и порога сбоев.
- [x] Обновленные бинарники скомпилированы и развернуты на серверах сети.
