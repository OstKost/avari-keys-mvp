# TASK-005: Master Frontend — Web UI интерфейс

## 1. Описание задачи (Specific)
Разработать современный, отзывчивый Web UI на React + Vite + Tailwind CSS для Master-сервера:
- **Страница авторизации и регистрации**:
  - Вход (username + password).
  - Регистрация с баннером "Учетная запись создана и ожидает подтверждения администратором".
- **Пользовательский кабинет**:
  - Карточки / список активных ключей пользователя с бейджами типа сервера ("Каскад M0->S1", "Прямой S2").
  - Кнопка "Создать ключ" (выбор типа подключения/сервера, имя устройства, например `iPhone`, `MacBook`).
  - Модальное окно просмотра ключа:
    - QR-код для быстрого импорта в Amnezia / WireGuard клиент.
    - Кнопка "Скопировать конфиг".
    - Кнопка "Скачать .conf файл".
  - Кнопка удаления ключа с подтверждением.
- **Панель администратора**:
  - Вкладка **Пользователи**: таблица зарегистрированных пользователей, переключатель статуса (Активировать / Деактивировать), удаление.
  - Вкладка **Серверы (Ноды)**: статус подключения (индикатор Online/Offline, Latency/Health), добавление новой ноды (Имя, Тип: Каскад/Прямой, URL API, Секретный токен).
  - Вкладка **Все ключи**: мониторинг всех ключей в системе, фильтр по пользователю и ноде.

## 2. Критерии приемки (Measurable)
- [ ] Адаптивный дизайн (корректно отображается на десктопе и смартфонах).
- [ ] Обработка состояний загрузки (Loading), ошибок (Error toast/alert) и пустых состояний (Empty state).
- [ ] QR-код генерируется четко и считывается мобильным приложением AmneziaWG.
- [ ] Поддержка скачивания `.conf` с корректным именем файла.
- [ ] Корректное скрытие админских разделов для пользователей без роли `admin`.
- [ ] Сборка `npm run build` завершается без ошибок типов и предупреждений линтера.

## 3. Достижимость (Achievable)
Используются Tailwind CSS, Lucide-React и легковесные компоненты.

## 4. Актуальность (Relevant)
Предоставляет конечным пользователям и администратору интуитивно понятный визуальный интерфейс для управления ключами.
