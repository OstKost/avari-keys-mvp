# TASK-006: Контрактные и интеграционные тесты

## 1. Описание задачи (Specific)
Реализовать набор контрактных и интеграционных тестов для проверки взаимодействия Master и Slave без запуска реального ядра AWG:
- Контрактный тест протокола Master $\leftrightarrow$ Slave (валидация форматов JSON, заголовков `X-API-Key`, обработки ошибок таймаута и неверных токенов).
- Сквозной интеграционный тест сценариев:
  1. Регистрация нового пользователя $\to$ попытка логина (ожидается 403 Forbidden).
  2. Логин под `admin` $\to$ активация пользователя.
  3. Успешный логин активированного пользователя.
  4. Добавление тестовой Slave-ноды (с мок-сервером).
  5. Генерация ключа пользователем $\to$ проверка вызова мок-скрипта $\to$ получение `.conf` и QR.
  6. Удаление ключа пользователем $\to$ проверка удаления на Slave и в БД SQLite.

## 2. Критерии приемки (Measurable)
- [ ] Все тесты выполняются командой `go test -v -race ./...` менее чем за 5 секунд.
- [ ] 100% покрытие критических путей авторизации и модерации.
- [ ] Отсутствие race conditions (проверено флагом `-race`).

## 3. Достижимость (Achievable)
Реализуется на стандартном пакете `net/http/httptest` в Go.

## 4. Актуальность (Relevant)
Гарантирует надежность приложения и защищает от регрессий при доработках.
