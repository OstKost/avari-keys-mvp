# Avari Keys MVP

Легковесная, надежная и распределенная система управления VPN-ключами AmneziaWG (AWG) поверх скрипта `manage_amneziawg.sh` ([bivlked/amneziawg-installer](https://github.com/bivlked/amneziawg-installer)).

---

## 🌟 Основные возможности

- **Каскадный и прямой VPN**: поддержка каскада из двух серверов (РФ $\to$ Зарубеж) для надежного обхода блокировок и автономных серверов для прямого подключения.
- **Минималистичная архитектура**: отсутствие тяжелых зависимостей, чистый Go + SQLite (без CGo), статические бинарники.
- **Безопасный Slave API**: тонкая HTTP API обвязка над `manage_amneziawg.sh` с авторизацией по токену и маскировочной заглушкой (Decoy).
- **Модерация пользователей**: регистрация пользователей с подтверждением учетной записи администратором.
- **Удобный Web UI**: современный личный кабинет пользователя (QR-коды, скачивание `.conf`) и панель администратора для управления пользователями и серверами.

```
                                        │                     │
                                        └──(API Token)──> (Slave API)
```
